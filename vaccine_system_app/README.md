# 疫苗预约与接种管理系统（前端）

## 📌 项目简介
本项目为儿童疫苗预约与接种管理系统前端，基于 UniApp 开发，实现管理员端、医生端、家长端三端业务功能。

## 🛠 技术栈
- UniApp
- Vue3
- Vuex
- RESTful API
- 微信小程序 / H5 多端支持

## 🎯 核心功能
### 👨‍👩‍👧 家长端
- 宝宝管理
- 疫苗预约
- 接种记录查询
- 接种点选择

### 👨‍⚕️ 医生端
- 当日预约查看
- 接种确认
- 接种记录录入

### 👨‍💼 管理员端
- 用户管理
- 疫苗管理
- 库存管理
- 接种点管理
- 数据统计

## 📐 项目架构
前后端分离架构，前端通过 Axios 封装请求模块与 Spring Boot 后端交互。

## 附录B：核心业务代码

### B.1 FEFO库存分配算法

```java
/**
 * FEFO（First Expiry First Out）库存分配算法
 * 优先分配即将过期的批次，确保疫苗在有效期内使用
 */
public SiteVaccineStock getFefoStockRow(Long siteId, Long vaccineId) {
    // 查询该疫苗在该接种点的所有可用批次（available_stock > 0）
    List<SiteVaccineStock> stocks = this.list(new LambdaQueryWrapper<SiteVaccineStock>()
            .eq(SiteVaccineStock::getSiteId, siteId)
            .eq(SiteVaccineStock::getVaccineId, vaccineId)
            .gt(SiteVaccineStock::getAvailableStock, 0)
            .orderByAsc(SiteVaccineStock::getExpiryDate));

    if (stocks == null || stocks.isEmpty()) {
        throw new BizException(BizErrorCode.STOCK_INSUFFICIENT);
    }

    // 返回最早过期的批次
    return stocks.get(0);
}
```

### B.2 预约创建服务

```java
@Transactional(rollbackFor = Exception.class)
public Appointment createOrderWithStockCheck(CreateAppointmentDTO dto) {
    Long userId = dto.getUserId();
    Long childId = dto.getChildId();
    Long vaccineId = dto.getVaccineId();
    Long siteId = dto.getSiteId();
    Long doctorScheduleId = dto.getDoctorScheduleId();

    // 1. 参数校验：用户角色、预约排班有效性、接种点状态
    SysUser user = sysUserService.getById(userId);
    if (!"RESIDENT".equals(user.getRole())) {
        throw new BizException(BizErrorCode.ROLE_NOT_RESIDENT);
    }

    // 2. 检查是否存在进行中的预约
    List<Appointment> pendingForChild = this.list(new LambdaQueryWrapper<Appointment>()
            .eq(Appointment::getChildId, childId)
            .in(Appointment::getStatus, AppointmentStatusEnum.BOOKED.getCode(),
                    AppointmentStatusEnum.CHECKED_IN.getCode(),
                    AppointmentStatusEnum.PRE_CHECK_PASS.getCode(),
                    AppointmentStatusEnum.OBSERVING.getCode()));
    if (!pendingForChild.isEmpty()) {
        throw new BizException(BizErrorCode.DUPLICATE_PENDING_APPOINTMENT);
    }

    // 3. FEFO锁定库存
    int stock = siteVaccineStockService.getAvailableStock(vaccineId, siteId);
    if (stock <= 0) throw new BizException(BizErrorCode.STOCK_INSUFFICIENT);

    SiteVaccineStock fefoRow = siteVaccineStockService.getFefoStockRow(siteId, vaccineId);
    boolean locked = siteVaccineStockService.lockStock(fefoRow.getId());
    Long batchId = fefoRow.getBatchId();

    // 4. 创建预约记录
    Appointment appointment = new Appointment();
    appointment.setUserId(userId);
    appointment.setChildId(childId);
    appointment.setVaccineId(vaccineId);
    appointment.setSiteId(siteId);
    appointment.setDoctorScheduleId(doctorScheduleId);
    appointment.setAppointmentDate(dto.getAppointmentDate());
    appointment.setStatus(AppointmentStatusEnum.BOOKED.getCode());
    appointment.setBatchId(batchId);
    save(appointment);

    return getById(appointment.getId());
}
```

### B.3 接种核销服务

```java
@Transactional(rollbackFor = Exception.class)
public VaccinationRecord completeVaccination(CompleteVaccinationDTO dto) {
    Long appointmentId = dto.getAppointmentId();
    Appointment appointment = this.getById(appointmentId);

    // 1. 校验预约状态
    if (!AppointmentStatusEnum.PRE_CHECK_PASS.getCode().equals(appointment.getStatus())) {
        throw new BizException(BizErrorCode.APPOINTMENT_STATUS_ERROR);
    }

    // 2. 生成疫苗追溯码
    String vaccineCode = generateVaccineCode(appointment);

    // 3. 扣减批次库存
    Long batchId = appointment.getBatchId();
    siteVaccineStockService.deductStock(batchId, appointment.getSiteId());

    // 4. 更新预约状态为留观中
    appointment.setStatus(AppointmentStatusEnum.OBSERVING.getCode());
    appointment.setObserveStartTime(new Date());
    this.updateById(appointment);

    // 5. 生成接种记录
    VaccinationRecord record = new VaccinationRecord();
    record.setAppointmentId(appointmentId);
    record.setUserId(appointment.getUserId());
    record.setChildId(appointment.getChildId());
    record.setVaccineId(appointment.getVaccineId());
    record.setBatchId(batchId);
    record.setSiteId(appointment.getSiteId());
    record.setDoctorId(appointment.getDoctorId());
    record.setVaccineCode(vaccineCode);
    record.setVaccinationDate(new Date());
    // ... 设置其他字段
    vaccinationRecordService.save(record);

    return record;
}
```

### C.1 环境要求

**后端环境**：
- JDK 17+
- Maven 3.9+
- MySQL 8.0+

**前端环境**：
- Node.js 18+
- HBuilderX（UniApp开发）

### C.2 项目启动

**后端启动**：
```bash
cd vaccine_system
mvn clean install
mvn spring-boot:run
```
服务启动后访问 http://localhost:8080

**前端启动**：
```bash
cd vaccine.app
# 使用HBuilderX打开项目
# 或使用命令行
npm install
npm run dev:%PLATFORM%
```

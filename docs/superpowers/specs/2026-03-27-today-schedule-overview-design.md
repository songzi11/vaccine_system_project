# 今日排班概览功能设计文档

**日期：** 2026-03-27
**功能：** 今日排班医生概览及快速换班

---

## 1. 需求背景

当前排班管理模块以时间段维度展示数据，管理员无法快速了解今天有哪些医生排班。当医生请假时，需要逐个时段修改，操作繁琐。

本功能提供今日排班医生概览视图，支持快速换班操作。

---

## 2. 功能概述

### 2.1 页面入口
- 路径：`pages/admin/schedule/today.vue`
- 入口：从排班列表页面 (`pages/admin/schedule/list.vue`) 添加"今日概览"按钮

### 2.2 核心功能
1. **医生排班概览**：展示今日所有排班医生及详细信息
2. **快速换班**：支持上午/下午/全天三个维度的换班操作
3. **换班医生选择**：弹窗选择顶班医生

## 4. 后端设计

### 4.1 数据模型

**今日排班概览响应对象 (TodayScheduleOverviewVO)**
```java
{
  "date": "2026-03-27",              // 日期
  "dayOfWeek": "星期四",               // 星期
  "doctors": [                        // 医生列表
    {
      "doctorId": 2,
      "doctorName": "张医生",
      "doctorGender": 1,               // 1=男 2=女
      "doctorPhone": "13800002001",
      "siteId": 1,
      "siteName": "天津市南开区接种点",
      "morningSlotCount": 16,         // 上午时段数
      "afternoonSlotCount": 8,         // 下午时段数
      "todayAppointmentCount": 12,      // 今日预约数
      "status": "normal",              // normal=全部启用, partial=部分禁用
      "schedules": [...]               // 该医生的所有排班记录（可选）
    }
  ]
}
```

### 4.2 API接口

#### 4.2.1 获取今日排班概览
```
GET /api/admin/doctor-schedule/today-overview

响应：
{
  "code": 200,
  "message": "成功",
  "data": TodayScheduleOverviewVO
}
```

#### 4.2.2 批量替换医生排班
```
POST /api/admin/doctor-schedule/batch-replace

请求体：
{
  "oldDoctorId": 2,           // 被替换的医生ID
  "newDoctorId": 7,           // 新医生ID
  "date": "2026-03-27",      // 日期（默认当天）
  "periodType": "morning"     // morning=上午, afternoon=下午, all=全天
}

响应：
{
  "code": 200,
  "message": "成功替换16个排班时段",
  "data": {
    "replacedCount": 16         // 实际替换的数量
  }
}
```

### 4.3 业务逻辑

#### 4.3.1 获取今日排班概览
1. 查询今天（`scheduleDate = today`）的所有排班记录
2. 按 `doctorId` 分组
3. 计算每个医生的统计信息（时段数、预约数等）
4. 返回分组后的概览数据

#### 4.3.2 批量替换排班
1. 查询指定日期、原医生ID的排班记录
2. 根据 `periodType` 过滤时段：
   - `morning`：时段开头小时 8-11
   - `afternoon`：时段开头小时 14-16
   - `all`：所有时段
3. 更新这些记录的 `doctorId` 为新医生ID
4. 返回更新数量

## 5. 交互流程

### 5.1 换班流程
```
1. 用户点击"上午换班"按钮
   ↓
2. 弹出换班弹窗，加载可用医生列表（排除当前医生）
   ↓
3. 用户选择顶班医生
   ↓
4. 调用 batch-replace 接口
   ↓
5. 显示加载状态
   ↓
6. 接口返回成功，提示"已替换16个时段"
   ↓
7. 重新加载今日排班概览
   ↓
8. 刷新排班列表页（如果已打开）
```

### 5.2 错误处理
- **无可用医生**：弹窗显示"暂无可用医生"
- **接口失败**：Toast提示错误信息，弹窗保持打开
- **网络超时**：显示重试按钮
